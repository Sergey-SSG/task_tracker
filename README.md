# 🎯 Task Tracker - Трекер задач сотрудников

Система для управления задачами сотрудников с аналитикой загруженности и приоритизацией задач.

## 🚀 Возможности

- **CRUD операции** для сотрудников и задач
- **Аналитика загруженности** сотрудников
- **Выявление важных задач** с рекомендациями по исполнителям
- **Валидация данных** и обработка ошибок
- **REST API** с документацией
- **Контейнеризация** с Docker

## 🛠 Технологии

- Python 3.11
- Django 4.2.7
- Django REST Framework
- PostgreSQL
- Docker & Docker Compose
- Swagger/ReDoc для документации
